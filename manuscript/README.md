# Manuscripts

Each submission has its own folder with its sources, figures, compiled PDFs
and the referee material that belongs to it.

```
manuscript/
├── jap/                          Journal of Applied Physics submission (current)
│   ├── sotc_jap.tex / .pdf       main text
│   ├── sotc_jap_supplementary.tex / .pdf
│   ├── cover_letter_jap.tex / .pdf
│   ├── refs_jap.bib
│   ├── tables/                   generated by codes/validation/make_jap_tables.py
│   ├── figures/                  generated by codes/validation/plot_*.py
│   ├── reviews/                  map of the PRB referee comments to this version (local only)
│   ├── Makefile                  `make` builds all three PDFs (aux files go to build/)
│   └── build/                    LaTeX auxiliary files (local only)
├── prb/                          earlier Physical Review B submission (BS15679)
│   ├── manuscript_original.tex / .pdf   as first submitted
│   ├── manuscript_clean.tex / .pdf      revised, uncolored
│   ├── manuscript_updated.tex / .pdf    revised, changes in blue
│   ├── cover_letter.tex / .pdf
│   ├── refs.bib, refs_original.bib
│   ├── figures/
│   ├── reviews/                  referee reports (local only) and
│   │                             response_to_reviewers.tex / .pdf
│   ├── FILE_MAP.md               details of the PRB files
│   └── manuscript.md, make_figures.py, convert_to_latex.py   (local drafting tools)
└── cpc/                          bibliography and figures of an earlier CPC draft (local only)
```

Build the JAP PDFs on Viper:

```bash
module load texlive/2021
cd manuscript/jap && make        # `make clean` removes build/
```

Files marked "local only" are excluded from the public repository by
`.gitignore` (referee reports, internal checklists, build output).
